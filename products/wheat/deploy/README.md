## 三、部署流程（我执行，你只需确认）

1. 本地打包 `deploy/pack_deploy.py` → `deploy/hello-agents-server.tar.gz`（已含代码/模型/评估CSV/.env）
2. `scp` 上传到服务器 `/tmp/`，解压到 `/opt/hello-agents`
3. 运行 `server_setup.sh`：装 Python 环境 + 依赖 + Qdrant + systemd 自启
4. 输出「手机访问地址 + 登录账号密码」
5. 手机浏览器打开 `http://<IP>:7865` 验证

## 四、开关说明（部署前可指定）

- 默认开：**登录保护**（自动生成密码，公网必需）、**Qdrant 向量库**
- 默认关（4G 内存机型省内存）：
  - `NEO4J=1` 启用图数据库（有 OOM 风险，需要时再加）
  - `OLLAMA=1` 启用视觉模型 qwen2.5vl:3b（CPU 推理慢；不开则视觉门控自动降级，**小麦检测不受影响**）

## 五、注意事项

- 图片训练集（GlobalWheat2020 等几千张）**未打包**（手机端用不到）；服务器上「实验数据查询」的图片数量会显示 0，其余模型/评估数据正常。
- 首次 RAG 检索 Qdrant 为空，问答先走知识库关键词检索；需要可后续补灌。
- 服务器是公网地址，务必保持 UI 登录保护开启；不要关闭 `/etc/hello-agents-ui.env`。
- 想用域名 + HTTPS（https://agri.xxx.com）时再找我，加 Nginx 反代即可。

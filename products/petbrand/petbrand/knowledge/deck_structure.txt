# 品牌全案提案页结构（攒案汇总骨架）

## 提案页应包含的板块（顺序固定）
1. 封面：品牌名 / 定位语 / 一句话提案主张 / 日期。
2. 品牌简报（brief 摘要）：给评审快速对齐「我们在给谁、做什么生意、要什么」。
3. 市场与竞品：大盘一句结论 + 渠道结构 + 竞品梯队 + 机会缺口。
4. 人群洞察：主人群画像 + 痛点/决策链路 + 情感需求（痛点与爽点并重）。
5. 品牌定位：目标人群选定 + 品类切口 + 差异化卖点 + 价值主张 + 定位语。
6. 品牌资产：候选品牌名 + 品牌口号 + VI 方向 + 品牌故事 + 人设口吻。
7. 落地动作（如已产出）：内容种草矩阵 / 渠道节奏 / 私域打法 / 预算分配（v2 扩展）。
8. 结尾页：下一步建议 + 需要拍板的决策点（名字选哪个/人群确认/预算确认）。

## 排版与演示要点
- 每板块一屏；先结论后论据；标题即结论（如「主粮是基本盘，零食做传播」）。
- 数字/图表标注演示口径；引用知识来源。
- 提案页生成 HTML（深色提案风格、分节可滚动放映），另给一份 Markdown 全案汇总便于复制修改。

## 一致性格言
整本案只说一件事：定位语。每个板块都要能回答「这页跟我们的定位有什么关系」。

## 自动测试的覆盖范围

- 人数与房间数分开计费，一日游零住宿，三日游两晚住宿。
- 删除后重算，不信任客户端传回的总额。
- Decimal 两位小数，较大合法单价的聚合。
- 未知门票、未安排的住宿夜保留未知状态。
- 非法日期、超过天数、房间多于人数、非法模式返回 422。
- 负价格、NaN、超过两位小数、非法坐标、重复日期、返程日酒店、缺失天气、重复餐别被拒绝。
- 配置接口不返回密钥；未配置真实模式返回 503；异常被收敛为不含原始秘密的 502。
- 高德 POI 字段解析，城市转 adcode，非法天气温度过滤，HTTP/业务错误处理。
- 使用实际框架的 MCP 内存传输执行工具调用。
- 使用实际 SimpleAgent，替换外部模型返回，验证三个检索角色、规划角色、一次 JSON 修复与未知景点 ID 拒绝。
- 可选 Unsplash 署名、限流降级、演示模式不触发图片请求、导入不能注入非允许来源的图片链接。
- PERT 工作量计算及非法预留比例校验。

## 当前功能边界

- 地图展示位置与游览顺序，不提供道路导航、真实距离或通行时间。
- 真实模式餐饮是可编辑的预算安排，不是已核实的餐厅推荐；酒店房价与市内交通费用也是预算预设。
- PDF/PNG 是光栅化的文字版行程，不包含在线地图与外部图片，PDF 文本不能直接选中。
- 只保存当前浏览器最近一次成功保存的行程；没有服务端数据库、用户账号与多人协作。
- 等待状态显示真实等待时长，未实现后台任务的逐阶段实时进度推送。
- 未执行公网部署、预订、支付或其他外部写操作。
